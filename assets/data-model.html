Pub/sub fan-out
subscribe() → asyncio.Queue register + replay buffer
unsubscribe(q)
broadcast(item) push to all subscribers
In-memory runtime state. Persistent SSE reader connects once at session creation, fans out to subscribers via replay buffer (maxlen=5000). ACP/inner session IDs are ephemeral — recreated on connect, restored via native session/load on resume.
