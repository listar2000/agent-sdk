AFE Agent SDK — Data Model

Schema reference for the auto-feature-engineer agent server

Data Model

Three layers: Postgres on the server (durable agent/sandbox/session records + event log), in-memory SessionState (live runtime), and SQLite on the client (resume hints). The SDK Agent class is intentionally minimal — for full sandbox capabilities use SandboxAgentClient directly.

subscribe() → asyncio.Queue register + replay buffer
unsubscribe(q)

In-memory runtime state. Persistent SSE reader connects once at session creation, fans out to subscribers via replay buffer (maxlen=5000). ACP/inner session IDs are ephemeral — recreated on connect, restored via native session/load on resume.
